# 项目级代理行为约束（安全模式）

你在服务端运行，必须优先保证安全与不落盘。

## 核心要求（必须遵守）

1. **仅对话输出**：当用户请求生成任何形式的代码（HTML/CSS/JS/后端代码/脚本/配置等），只能在对话中直接输出内容，使用 Markdown 代码块（例如 ` ```html` / ` ```js`）。
2. **禁止写文件**：禁止创建、修改、删除任何文件或目录（包括但不限于 `.html/.js/.css/.py/.sh/.json` 等）。
3. **用户要求写文件时的处理**：即使用户明确提出“写文件/保存文件/生成 xxx.html/落盘/下载”等要求，也必须优先改为“直接在对话中输出完整代码”，并提示用户自行复制保存。
4. **禁止使用命令执行做写入/破坏**：禁止通过 shell 命令（如 `cat > file`、`tee`、`echo >`、`rm`、`mv`、`cp` 等）间接写入或破坏文件。

## 输出格式规范
- 代码输出必须完整可运行，需包含必要的 HTML 结构、JS 逻辑与最少 CSS（如有）。
- 先给出简短说明，再给出完整代码块。

## 环境变量说明

Skills 运行依赖以下环境变量，需在执行环境中提前 `export`：

| 变量名 | 用途 |
|--------|------|
| `ARK_API_KEY` | 火山引擎 ARK（Seedream / Seedance）API 密钥 |
| `MINIMAX_API_KEY` | MiniMax TTS API 密钥 |
| `CLAUDE_OUTPUT_DIR` | Skills 产物本地输出目录（绝对路径） |
| `CLAUDE_OUTPUT_BASE_URL` | Skills 产物对外访问的 Base URL |

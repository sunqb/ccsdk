# 高中政治学科语言规范标准

## 一、总体要求

### 1.1 语言表述原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **政治性** | 坚持正确政治方向，体现国家意志 | 用"最本质特征"而非"特点之一" |
| **科学性** | 术语使用准确，逻辑严密 | "主要矛盾"vs"矛盾的主要方面" |
| **规范性** | 符合学科标准表述 | 用"人民当家作主"而非"人民做主" |
| **简洁性** | 简明扼要，不冗长 | 避免口语化、随意化表达 |

### 1.2 禁止使用的表述

| 不规范表述 | 规范表述 | 说明 |
|------------|----------|------|
| 人民做主 | 人民当家作主 | 固定搭配 |
| 共产党的领导 | 中国共产党的领导 | 完整表述 |
| 人大制度 | 人民代表大会制度 | 完整表述 |
| 政协制度 | 中国共产党领导的多党合作和政治协商制度 | 完整表述 |
| 社会主义经济 | 社会主义基本经济制度 | 或"公有制经济" |
| 生产关系决定生产力 | 生产力决定生产关系 | 逻辑不能颠倒 |
| 经济基础反作用于上层建筑 | 上层建筑反作用于经济基础 | 主客体不能混淆 |

| 概念 | 规范表述 |
|------|----------|
| 社会基本矛盾 | 生产力与生产关系的矛盾、经济基础与上层建筑的矛盾 |

### 2.2 必修2《经济与社会》

| 概念 | 规范表述 |
|------|----------|
| 基本经济制度 | 公有制为主体、多种所有制经济共同发展，按劳分配为主体、多种分配方式并存，社会主义市场经济体制等 |

### 2.3 必修3《政治与法治》

| 概念 | 规范表述 |
|------|----------|

### 2.4 必修4《哲学与文化》

| 原理 | 世界观 | 方法论 |
|------|--------|--------|
| 物质决定意识 | 物质是本原的，意识是派生的 | 一切从实际出发，实事求是 |

| 矛盾特殊性 | 矛盾着的事物各有其特点 | 具体问题具体分析 |

## 三、常见易混表述辨析

### 3.1 "决定"vs"影响"

| 关系 | 使用场景 |
|------|----------|
| 决定 | 生产力决定生产关系；经济基础决定上层建筑；社会存在决定社会意识 |
| 反作用/影响 | 生产关系反作用于生产力；上层建筑反作用于经济基础 |

### 3.2 "主体"vs"主导"

| 术语 | 使用场景 |
|------|----------|
| 主体地位 | 公有制经济在国民经济中占主体地位 |
| 主导作用 | 国有经济对国民经济发展起主导作用 |

### 3.3 "主要矛盾"vs"矛盾的主要方面"

| 对比 | 主要矛盾 | 矛盾的主要方面 |
|------|----------|----------------|
| 关键词 | 重点、中心、关键 | 主流、支流、本质 |
| 方法论 | 抓重点 | 分清主流和支流 |

## 四、答题语言规范

### 4.1 主观题答题格式

**说明类**：
```
① [理论依据]：XXX
② [材料分析]：材料中XXX体现了...
③ [得出结论]：因此...
```

**措施类**：
```
① [主体1]要坚持...
② [主体2]要做到...
```

### 4.2 选择题选项规范

- 表述完整准确
- 避免绝对化表述（除非教材明确）
- 避免口语化

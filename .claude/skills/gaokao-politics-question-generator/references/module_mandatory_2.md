# 必修2：经济与社会

## 模块概述

本模块从经济制度和经济体制角度，阐释中国特色社会主义经济建设的基本原理，包括我国的基本经济制度、社会主义市场经济体制特征、高质量发展、收入分配、社会保障等内容。

## 单元一：生产资料所有制与经济体制

### 1.1 公有制为主体 多种所有制经济共同发展
**核心概念**：
- 生产资料所有制的地位和作用
- 公有制经济的构成和地位
- 国有经济的主导作用
- 非公有制经济的地位和作用
- 两个"毫不动摇"

**关键考点**：
- 公有制经济：国有经济、集体经济、混合所有制经济中的国有成分和集体成分
- 国有经济：控制国民经济命脉，对经济发展起主导作用
- 非公有制经济：个体经济、私营经济、外资经济、混合所有制经济中的非公有制成分
- 公有制经济和非公有制经济都是社会主义市场经济的重要组成部分

### 1.2 坚持"两个毫不动摇"
**核心概念**：
- 毫不动摇巩固和发展公有制经济
- 毫不动摇鼓励、支持、引导非公有制经济发展
- 发展壮大国有经济的要求
- 发展壮大农村集体经济的途径
- 促进非公有制经济发展的措施

**关键考点**：
- 国有经济布局优化和结构调整
- 国有企业改革：增强国有经济竞争力、创新力、控制力、影响力、抗风险能力
- 农村基本经营制度：家庭承包经营为基础、统分结合的双层经营体制
- 优化营商环境，构建亲清政商关系

### 1.3 充分发挥市场在资源配置中的决定性作用
**核心概念**：
- 资源配置的手段：计划和市场
- 市场配置资源的机制：价格、供求、竞争
- 市场调节的优点和局限性
- 市场体系的构成和特征
- 建设现代市场体系的要求

**关键考点**：
- 市场在资源配置中起决定性作用
- 市场调节存在自发性、盲目性、滞后性等弊端
- 统一开放、竞争有序的市场体系是市场在资源配置中起决定性作用的基础
- 建立公平开放透明的市场规则

### 1.4 更好发挥政府作用
**核心概念**：
- 社会主义市场经济体制的基本特征
- 政府经济职能的内容
- 宏观调控的目标和手段
- 财政政策和货币政策

**关键考点**：
- 社会主义市场经济体制的四大特征：
  1. 坚持党的领导（最本质特征、最大优势）
  2. 共同富裕的根本目标
  3. 科学的宏观调控、有效的政府治理
  4. 与社会主义基本经济制度结合
- 宏观调控的主要目标：促进经济增长、增加就业、稳定物价、保持国际收支平衡
- 宏观调控的手段：经济手段（主要）、法律手段、行政手段

## 单元二：经济发展与社会进步

### 2.1 坚持新发展理念
**核心概念**：
- 以人民为中心的发展思想
- 五大发展理念：创新、协调、绿色、开放、共享
- 每个发展理念的内涵和要求

**关键考点**：
| 发展理念 | 解决问题 | 具体要求 |
|----------|----------|----------|
| 创新 | 发展动力问题 | 创新是第一动力，摆在国家发展全局的核心位置 |
| 协调 | 发展不平衡问题 | 促进城乡区域协调发展、经济社会协调发展 |
| 绿色 | 人与自然和谐共生问题 | 坚持绿水青山就是金山银山 |
| 开放 | 发展内外联动问题 | 互利共赢的开放战略 |
| 共享 | 社会公平正义问题 | 发展为了人民、依靠人民、成果由人民共享 |

### 2.2 推动高质量发展
**核心概念**：
- 高质量发展的内涵
- 建设现代化经济体系
- 供给侧结构性改革
- 实体经济的重要性
- 实施乡村振兴战略和区域协调发展战略

**关键考点**：
- 高质量发展是全面建设社会主义现代化国家的首要任务
- 现代化经济体系的构成：创新引领、协同发展的产业体系；统一开放、竞争有序的市场体系等
- 供给侧结构性改革：去产能、去库存、去杠杆、降成本、补短板
- 实体经济是一国经济的立身之本，是财富创造的根本源泉
- 加快建设制造强国、质量强国

### 2.3 我国的个人收入分配与社会保障
**核心概念**：
- 我国的收入分配制度
- 按劳分配和按生产要素分配
- 完善个人收入分配的措施
- 社会保障的作用和内容
- 完善社会保障体系的要求

**关键考点**：
- 收入分配方式：按劳分配（主体）、按生产要素分配
- 生产要素：劳动、资本、土地、知识、技术、管理、数据等
- 完善收入分配：两个同步（居民收入增长和经济增长同步、劳动报酬提高和劳动生产率提高同步）
- 社会保障的"安全网"作用：减震器、调节器
- 社会保障体系：社会保险（核心）、社会救助（最后防线）、社会福利、社会优抚等

## 常见设问角度

1. **说明类**：运用"我国的生产资料所有制"知识，说明为什么要坚持"两个毫不动摇"
2. **分析类**：分析市场在资源配置中起决定性作用的机制
3. **措施类**：为推动高质量发展提出合理化建议
4. **论证类**：论证贯彻新发展理念的必要性
5. **评价类**：评价某项经济政策或现象

## 易混淆知识点

| 易混点 | 正确理解 |
|--------|----------|
| 公有制的主体地位vs国有经济的主导作用 | 公有制是主体（量+质），国有经济是主导（控制力） |
| 社会主义市场经济vs社会主义经济 | 前者包括公有制和非公有制，后者主要指公有制经济 |
| 按劳分配vs按劳动要素分配 | 按劳分配在公有制经济中，按劳动要素在非公有制经济中 |
| 初次分配vs再分配 | 初次在企业/市场，再分配通过税收、社保、转移支付 |

## 超纲预警

解析时严禁出现以下超纲内容：
- 西方经济学完整理论（如IS-LM模型、菲利普斯曲线等）
- 马克思主义政治经济学的完整资本论内容
- 微观经济学的市场结构理论（完全竞争、垄断等）
- 宏观经济学的乘数效应、加速原理等
- 国际经济学中的汇率决定理论

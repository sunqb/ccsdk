# 难度与区分度评估指南

## 一、难度评估

### 1.1 难度系数计算公式

```
难度系数 P = 1 - (平均分 / 满分)

或者：P = 答对人数 / 总人数（对于选择题）
```

### 1.2 难度等级划分

| 等级 | 难度系数范围 | 说明 | 适用场景 |
|------|-------------|------|----------|
| **容易** | 0.7 - 0.9 | 基础知识直接考查，大部分考生能答对 | 保证得分率，增强信心 |
| **中等** | 0.4 - 0.7 | 需要理解应用，考查核心能力 | 主体题目，体现课标要求 |
| **较难** | 0.2 - 0.4 | 综合分析能力要求高 | 区分中上水平考生 |
| **难** | 0.0 - 0.2 | 高阶思维要求，需要创新思考 | 选拔顶尖考生 |

### 1.3 影响难度的因素

#### 知识层面
- **知识深度**：
  - 简单：单一知识点，直接记忆
  - 中等：多个知识点的简单组合
  - 较难：知识点深度理解和迁移
  - 难：跨模块知识整合

- **知识范围**：
  - 简单：单个知识点
  - 中等：同单元内多个知识点
  - 较难：跨单元知识点
  - 难：跨模块知识综合

#### 能力层面
- **思维层次**（根据布鲁姆认知目标分类）：

| 层次 | 能力要求 | 难度对应 |
|------|----------|----------|
| 记忆 | 识别、回忆知识点 | 容易 |
| 理解 | 解释、举例、分类、总结 | 容易-中等 |
| 应用 | 运用知识解决新问题 | 中等 |
| 分析 | 区分、组织、归因 | 中等-较难 |
| 评价 | 判断、批判、检验 | 较难 |
| 创造 | 生成、计划、建构 | 难 |

#### 题目设计层面
- **情境复杂度**：
  - 简单：教材原话、直述情境
  - 中等：改编情境，需要提取信息
  - 较难：新材料，需要理解和转化
  - 难：复杂现实情境，多角度分析

- **设问方式**：
  - 简单："是什么"、"有哪些"
  - 中等："为什么"、"说明什么"
  - 较难："如何理解"、"分析原因"
  - 难："论证"、"评析"、"提出方案"

- **干扰项设计**（选择题）：
  - 简单：干扰项明显错误
  - 中等：干扰项有一定迷惑性
  - 较难：干扰项与正确答案接近
  - 难：多个选项都有一定道理，需精细辨析

### 1.4 高考政治各题型参考难度

| 题型 | 建议难度范围 | 备注 |
|------|-------------|------|
| 选择题（简单） | 0.7 - 0.85 | 基础知识考查 |
| 选择题（中等） | 0.5 - 0.7 | 理解应用 |
| 选择题（较难） | 0.35 - 0.5 | 综合分析 |
| 非选择题（基础问） | 0.55 - 0.7 | 直接运用知识 |
| 非选择题（综合问） | 0.4 - 0.55 | 多角度分析 |
| 非选择题（开放问） | 0.3 - 0.45 | 创新应用 |

## 二、区分度评估

### 2.1 区分度计算公式

```
区分度 D = 高分组通过率 - 低分组通过率

高分组：成绩前27%的考生
低分组：成绩后27%的考生
```

### 2.2 区分度等级划分

| 等级 | 区分度范围 | 评价 | 处理建议 |
|------|-----------|------|----------|
| **优秀** | ≥ 0.4 | 能有效区分不同层次考生 | 保留使用 |
| **良好** | 0.3 - 0.39 | 可接受水平 | 保留使用 |
| **合格** | 0.2 - 0.29 | 有一定区分作用 | 可保留，建议微调 |
| **较差** | 0 - 0.19 | 区分作用弱 | 建议修改或淘汰 |
| **异常** | < 0 | 高分组答错多，可能题目有问题 | 必须修改或淘汰 |

### 2.3 影响区分度的因素

#### 题目本身
- **难度适中**：
  - 过易（P > 0.9）：大家都对，无区分度
  - 过难（P < 0.2）：大家都错，无区分度
  - 最佳难度：0.4 - 0.7

- **考查能力层次**：
  - 仅考查记忆：区分度低
  - 考查理解应用：区分度中等
  - 考查分析评价：区分度高

#### 考生群体
- 考生群体同质性高 → 区分度低
- 考生群体异质性高 → 区分度高

### 2.4 提高区分度的方法

1. **精准定位考查目标**
   - 明确考查什么知识点
   - 明确考查什么能力层次

2. **优化情境设计**
   - 使用新材料、新情境
   - 情境与知识点关联适度隐藏

3. **科学设置选项**（选择题）
   - 干扰项要有迷惑性
   - 错误选项要有典型性
   - 选项表述要规范准确

4. **合理设置问题梯度**
   - 由浅入深
   - 层层递进
   - 设置思维障碍点

## 三、难度与区分度的关系

### 3.1 理想状态

理想的高考试题应具备：
- **合理的难度梯度**：容易:中等:较难 = 3:5:2
- **良好的区分功能**：大部分题目区分度在0.3以上

| 较难 | 15-20% | 0.4+ | 选拔优秀人才 |
| 难 | 5-10% | 0.3-0.4 | 区分顶尖学生 |

## 四、评估流程

### 4.1 分析阶段

1. **分析知识考查**
   - 考查什么知识点
   - 属于哪个模块、单元
   - 知识点的认知要求

2. **分析能力要求**
   - 记忆 / 理解 / 应用 / 分析 / 评价 / 创造
   - 思维层次

3. **分析情境特点**
   - 新材料程度
   - 情境复杂度
   - 信息提取难度

4. **分析设问特点**
   - 设问角度
   - 答题要求
   - 思维跨度

### 4.2 初步判断

根据以上分析，初步判断：
- 难度系数范围
- 预期区分度等级

### 4.3 对比调整

- 与高考真题对比
- 与课标要求对比
- 与考生水平对比

### 4.4 形成结论

输出评估报告：
```
📊 难度评估
   • 难度系数：X.XX（[等级]）
   • 判断依据：[简述原因]

📈 区分度评估
   • 预期区分度：[等级]（约X.XX）
   • 适合考生层次：[如：中等偏上]
   • 判断依据：[简述原因]
```

## 五、仿写题的难度控制

### 5.1 仿写原则

仿写题目与原文的难度偏差应控制在 **±0.1** 以内

### 5.2 难度调整方法

| 要降低难度 | 要提高难度 |
|-----------|-----------|
| 减少知识点数量 | 增加知识点数量 |
| 使用更直接的设问 | 使用更综合的设问 |
| 减少情境复杂度 | 增加情境复杂度 |
| 增加提示性语言 | 减少提示性语言 |
| 选项区分度降低 | 选项区分度提高 |
| 缩短思维链条 | 延长思维链条 |

### 5.3 质量检查清单

- [ ] 难度系数偏差 ≤ 0.1
- [ ] 考查知识点一致
- [ ] 能力层次一致或合理调整
- [ ] 题型保持一致
- [ ] 预期区分度合理

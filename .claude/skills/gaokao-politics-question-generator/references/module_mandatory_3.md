# 必修3：政治与法治

## 模块概述

本模块围绕"中国共产党的领导、人民当家作主、全面依法治国"三条主线，阐释中国特色社会主义政治发展的道路、理论、制度，展现中国政治制度的特色和优势。

## 单元一：中国共产党的领导

### 1.1 中华人民共和国成立前各种政治力量
**核心概念**：
- 近代中国基本国情和社会主要矛盾
- 各种政治力量解决中国问题的方案
- 中国共产党执政是历史和人民的选择

**关键考点**：
- 20世纪上半叶中国三种建国方案：
  1. 地主阶级和买办性的大资产阶级方案（被推翻）
  2. 民族资产阶级方案（行不通）
  3. 工人阶级和其他进步势力方案（胜利）
- 中国共产党人的初心和使命：为中国人民谋幸福，为中华民族谋复兴
- 没有共产党就没有新中国

### 1.2 中国共产党领导人民站起来、富起来、强起来
**核心概念**：
- 中国共产党带领人民建立新中国（站起来）
- 中国共产党领导改革开放（富起来）
- 中国共产党领导新时代（强起来）
- 党的领导是中国特色社会主义最本质的特征

**关键考点**：
- 党的历史贡献：完成新民主主义革命、完成社会主义革命、进行改革开放
- 党的领导是中国特色社会主义制度的最大优势
- 党是最高政治领导力量

### 1.3 中国共产党的先进性
**核心概念**：
- 党的性质：中国工人阶级的先锋队，中国人民和中华民族的先锋队
- 党的根本宗旨：全心全意为人民服务
- 党的根本立场：人民立场
- 党的执政理念：立党为公、执政为民
- 党的指导思想与时俱进

**关键考点**：
- 党的性质和根本宗旨决定党始终代表最广大人民根本利益
- 党坚持以人民为中心的发展思想
- 党坚持解放思想、实事求是、与时俱进、求真务实
- 发挥共产党员的先锋模范作用

### 1.4 坚持和加强党的全面领导
**核心概念**：
- 党的政治领导、思想领导、组织领导
- 新时代坚持和加强党的全面领导的要求
- 坚持全面从严治党
- 坚持科学执政、民主执政、依法执政

**关键考点**：
- 党的领导是全面的、系统的、整体的
- 两个维护：坚决维护习近平总书记党中央的核心、全党的核心地位，坚决维护党中央权威和集中统一领导
- 全面从严治党是推进党的建设新的伟大工程的必然要求
- 依法执政是党执政的基本方式

## 单元二：人民当家作主

### 2.1 人民民主专政的社会主义国家
**核心概念**：
- 我国的国家性质：人民民主专政的社会主义国家
- 人民民主专政的本质：人民当家作主
- 全过程人民民主
- 我国国家职能

**关键考点**：
- 人民民主是最广泛、最真实、最管用的民主
- 全过程人民民主：全链条、全方位、全覆盖的民主
- 民主选举、民主协商、民主决策、民主管理、民主监督
- 对人民民主，对敌人专政，两者统一

### 2.2 人民代表大会：我国的国家权力机关
**核心概念**：
- 人民代表大会制度的地位和作用
- 全国人民代表大会的职权
- 人大代表的地位、权利和义务
- 坚持和完善人民代表大会制度

**关键考点**：
- 人民代表大会是我国的国家权力机关
- 全国人大是最高国家权力机关，行使最高立法权、决定权、任免权、监督权
- 人大代表：审议权、表决权、提案权、质询权
- 人民代表大会制度是我国的根本政治制度

### 2.3 人民代表大会制度：我国的根本政治制度
**核心概念**：
- 人民代表大会制度的组织和活动原则：民主集中制
- 人民代表大会制度的优势
- 坚持和完善人民代表大会制度的要求

**关键考点**：
- 民主集中制的表现：
  1. 人大与人民的关系
  2. 人大与其他国家机关的关系
  3. 中央与地方国家机构的关系
- 人民代表大会制度的优越性：
  1. 保障人民当家作主
  2. 动员全体人民投身社会主义建设
  3. 保证国家机关协调高效运转
  4. 维护国家统一和民族团结

### 2.4 中国共产党领导的多党合作和政治协商制度
**核心概念**：
- 中国特色社会主义政党制度
- 中国共产党的领导是多党合作的首要前提和根本保证
- 人民政协的性质和职能
- 这一制度的优越性

**关键考点**：
- 我国政党制度的基本内容：
  1. 中国共产党是执政党，各民主党派是参政党
  2. 多党合作的基本方针：长期共存、互相监督、肝胆相照、荣辱与共
  3. 根本活动准则：宪法
  4. 重要机构：人民政协
- 人民政协：爱国统一战线组织，职能是政治协商、民主监督、参政议政

### 2.5 民族区域自治制度
**核心概念**：
- 我国是统一的多民族国家
- 我国处理民族关系的方针
- 民族区域自治制度的内容和优越性
- 我国的宗教政策与法律

**关键考点**：
- 新型民族关系：平等团结互助和谐
- 处理民族关系的方针：民族平等、民族团结、各民族共同繁荣
- 民族区域自治是在国家统一领导下，各少数民族聚居的地方实行区域自治
- 自治权是民族区域自治制度的核心内容
- 我国宗教政策：宗教信仰自由政策、依法管理宗教事务、坚持独立自主自办原则、积极引导宗教与社会主义社会相适应

### 2.6 基层群众自治制度
**核心概念**：
- 基层群众自治的组织形式
- 人民群众直接行使民主权利的实践
- 基层群众自治制度的意义

**关键考点**：
- 基层群众自治组织：村民委员会、居民委员会、职工代表大会
- 基层民主实践：民主选举、民主协商、民主决策、民主管理、民主监督
- 发展基层民主的意义：保障人民享有更多更切实的民主权利，是社会主义民主政治建设的基础性工程

## 单元三：全面依法治国

### 3.1 我国法治建设的历程
**核心概念**：
- 我国法律发展的历史
- 马克思主义法律思想
- 新中国法治建设的成就
- 全面依法治国的总目标

**关键考点**：
- 法律的本质：统治阶级意志的体现（马克思主义观点）
- 法的决定因素：社会物质生活条件
- 全面依法治国总目标：建设中国特色社会主义法治体系、建设社会主义法治国家
- 全面依法治国是中国特色社会主义的本质要求和重要保障

### 3.2 全面依法治国的原则
**核心考点**：
- 坚持中国共产党的领导
- 坚持人民主体地位
- 坚持法律面前人人平等
- 坚持依法治国和以德治国相结合
- 坚持从中国实际出发

### 3.3 法治国家
**核心概念**：
- 法治国家的内涵
- 建设法治国家的措施
- 建设法治国家的意义

**关键考点**：
- 法治国家：依法治国、依宪治国、依法执政、依宪执政
- 坚持宪法法律至上
- 坚持良法之治
- 尊重和保障公民权利

### 3.4 法治政府
**核心概念**：
- 法治政府的内涵
- 建设法治政府的措施
- 建设法治政府的意义

**关键考点**：
- 职能科学、权责法定、执法严明、公开公正、智能高效、廉洁诚信、人民满意的法治政府
- 政府要依法行政，全面履行政府职能
- 规范执法自由裁量权，严格规范公正文明执法

### 3.5 法治社会
**核心概念**：
- 法治社会的内涵
- 建设法治社会的措施
- 建设法治社会的意义

**关键考点**：
- 法治社会：法律得到普遍公认和遵从、社会治理依法开展
- 深入开展法治宣传教育
- 提高社会治理法治化水平
- 建设完备的法律服务体系
- 健全社会矛盾纠纷预防化解机制

### 3.6 科学立法
**核心概念**：
- 科学立法的内涵
- 科学立法的标准
- 推进科学立法的要求

**关键考点**：
- 科学立法要尊重和体现社会发展的客观规律
- 科学立法要做到依法立法、民主立法
- 科学立法要合理设定权利与义务、权力与责任

### 3.7 严格执法
**核心概念**：
- 严格执法的内涵
- 严格执法的意义
- 推进严格执法的要求

**关键考点**：
- 严格执法是建设法治中国的关键
- 行政机关是执法的最重要主体
- 全面履行政府职能，坚持法定职责必须为、法无授权不可为
- 规范执法程序，坚持公正执法、文明执法

### 3.8 公正司法
**核心概念**：
- 公正司法的内涵
- 公正司法的意义
- 推进公正司法的要求

**关键考点**：
- 公正司法是维护社会公平正义的最后一道防线
- 确保审判权和检察权依法独立行使
- 坚持以事实为根据、以法律为准绳
- 坚持人民司法为人民

### 3.9 全民守法
**核心概念**：
- 全民守法的内涵
- 全民守法的意义
- 推进全民守法的要求

**关键考点**：
- 全民守法是建设法治社会的基础工程
- 全民守法要求依法行使权利、依法履行义务
- 加强公民道德建设，增强法治的道德底蕴

## 常见设问角度

1. **原因类**：说明必须坚持中国共产党领导的原因
2. **意义类**：说明发展全过程人民民主的意义
3. **措施类**：说明如何推进全面依法治国
4. **关系类**：说明党的领导、人民当家作主、依法治国的有机统一
5. **分析类**：分析某项政治制度的优势

# 选必3：逻辑与思维

## 模块概述

本模块阐述科学思维的基本知识，包括逻辑思维的规则、辩证思维的方法和创新思维的技巧，帮助学生提高思维能力，学会运用科学思维方法认识事物、解决问题。

## 第一单元：树立科学思维观念

### 1.1 思维的含义与特征
**核心概念**：
- 思维的含义
- 思维的特征：间接性、概括性、能动性
- 思维的基本形态：形象思维、抽象思维

**关键考点**：
- 思维是人脑对客观事物的反映
- 思维的间接性：凭借获得的感性材料、经验和知识，透过事物现象，揭示事物本质和规律
- 思维的概括性：从多种事物及其各种属性中，舍去表面的、非本质的属性，抓住内在的、共同的、本质的属性
- 思维的能动性：能够提炼加工感性材料，形成对客观事物的认识
- 形象思维：以感性形象作为思维的基本单元
- 抽象思维：以概念、判断和推理等反映认识对象，揭示事物的本质和规律

### 1.2 思维形态及其特征
**核心概念**：
- 不同思维形态的划分标准
- 抽象思维和形象思维的区别

**关键考点**：
- 按思维的方向分：发散思维和聚合思维
- 按思维对认识对象的思考角度分：综合思维和分析思维
- 按思维反映认识对象的方式分：辩证思维和形而上学思维
- 按思维的基本单元分：抽象思维和形象思维
- 抽象思维的基本形式：概念、判断、推理
- 形象思维的基本形式：感觉、知觉、表象

### 1.3 科学思维的含义与特征
**核心概念**：
- 科学思维的含义
- 科学思维的特征
- 学习科学思维的意义

**关键考点**：
- 科学思维是符合认识规律、遵循逻辑规则的思维，是能够达到正确认识结果的思维
- 科学思维的特征：
  1. 追求认识的客观性
  2. 结果具有预见性
  3. 结果具有可检验性
- 学习科学思维的意义：有助于我们认清社会发展规律，提高辨别是非的能力；有助于我们提高学习和工作效率；有助于我们树立科学的世界观和人生观

## 第二单元：遵循逻辑思维规则

### 2.1 "逻辑"的多种含义
**核心概念**：
- 逻辑的不同用法
- 形式逻辑的研究对象

**关键考点**：
- "逻辑"的不同用法：
  1. 规律（如：事物的逻辑）
  2. 逻辑规律与规则（如：说话要合乎逻辑）
  3. 认识问题的某种思维方法（如：霸权主义逻辑）
  4. 逻辑学（如：学点逻辑）
- 形式逻辑的核心任务：要把握从真前提推导出真结论的规律和规则

### 2.2 逻辑思维的基本要求
**核心概念**：
- 同一律
- 矛盾律
- 排中律

**关键考点**：
- **同一律**：在同一思维过程中，每一思想必须保持自身同一性。公式：A是A。违反同一律会犯"偷换概念"或"偷换论题"的逻辑错误。
- **矛盾律**：在同一思维过程中，两个互相矛盾的思想不能同真，必有一假。公式：A不是非A。违反矛盾律会犯"自相矛盾"的逻辑错误。
- **排中律**：在同一思维过程中，两个互相矛盾的思想不能同假，必有一真。公式：A或者非A。违反排中律会犯"两不可"的逻辑错误。

### 2.3 正确运用概念
**核心概念**：
- 概念的含义和特征
- 概念的基本特征：内涵和外延
- 概念外延间的关系

**关键考点**：
- 概念是反映事物本质属性的思维形式
- 概念的内涵：概念所反映的事物的本质属性（是什么）
- 概念的外延：具有概念所反映的本质属性的事物的范围（有哪些）
- 概念外延间的关系：
  1. 相容关系：全同关系、属种关系、种属关系、交叉关系
  2. 不相容关系：矛盾关系、反对关系

### 2.4 明确概念的方法
**核心概念**：
- 定义
- 划分

**关键考点**：
- 定义：用简明的语句揭示概念所反映的客观事物的本质属性
- 定义的结构：被定义项、定义联项、定义项
- 定义的规则：定义项与被定义项的外延必须全同；定义项不能直接或间接地包含被定义项；定义一般不能用否定形式；定义不能用比喻
- 划分：把一个属概念分成若干种概念
- 划分的结构：母项、子项
- 划分的规则：子项的外延之和必须等于母项的外延；在同一次划分中，只能用同一个标准；划分应该逐级进行，不能越级

### 2.5 正确运用判断
**核心概念**：
- 判断的含义和特征
- 判断的类型

**关键考点**：
- 判断是对认识对象有所断定的思维形式
- 判断的基本特征：
  1. 对认识对象有所断定（肯定或否定）
  2. 判断有真假之分
- 判断的类型：
  - 简单判断：性质判断、关系判断
  - 复合判断：联言判断、选言判断、假言判断

### 2.6 正确运用简单判断
**核心概念**：
- 性质判断（直言判断）
- 关系判断

**关键考点**：
- 性质判断的构成：量项、主项、联项、谓项
- 性质判断的类型：
  1. 全称肯定判断（所有S是P）
  2. 全称否定判断（所有S不是P）
  3. 特称肯定判断（有些S是P）
  4. 特称否定判断（有些S不是P）
  5. 单称肯定判断（这个S是P）
  6. 单称否定判断（这个S不是P）
- 关系判断：断定认识对象之间关系的判断

### 2.7 正确运用复合判断
**核心概念**：
- 联言判断
- 选言判断
- 假言判断（条件判断）

**关键考点**：
- **联言判断**：断定几种事物情况同时存在的判断。形式：p并且q。逻辑性质：当且仅当，组成它的各个联言支都是真的，这个联言判断才是真的。
- **选言判断**：断定对象可能情况的判断。
  - 相容选言判断：p或者q（可以同真）
  - 不相容选言判断：要么p，要么q（不能同真）
- **假言判断（条件判断）**：断定事物某情况的存在（或不存在）是另一情况存在（或不存在）的条件的判断。
  - 充分条件假言判断：如果p，那么q（有p必有q）
  - 必要条件假言判断：只有p，才q（无p必无q）
  - 充分必要条件假言判断：当且仅当p，才q

### 2.8 学会归纳与类比推理
**核心概念**：
- 推理的含义和类型
- 演绎推理、归纳推理、类比推理

**关键考点**：
- 推理：由一个或几个已知判断推出一个新判断的思维形式
- 推理的类型：
  - 演绎推理：从一般性前提推出个别性结论（必然推理）
  - 归纳推理：从个别性前提推出一般性结论（或然推理）
  - 类比推理：根据两个或两类对象在一些属性上相同或相似，推出它们在其他属性上也相同或相似（或然推理）

### 2.9 掌握演绎推理方法
**核心概念**：
- 三段论推理
- 换质位法

**关键考点**：
- **三段论**：由两个含有一个共同项的性质判断作前提，得出一个新的性质判断为结论的推理
- 三段论的结构：大项（结论的谓项）、小项（结论的主项）、中项（在前提中出现两次）
- 三段论规则：
  1. 一个三段论只能有三个不同的项
  2. 中项在前提中至少周延一次
  3. 前提中不周延的项在结论中不得周延
  4. 两个否定的前提不能必然推出结论
  5. 前提中有一个是否定的，结论是否定的

### 2.10 学会归纳与类比推理（续）
**核心概念**：
- 完全归纳推理
- 不完全归纳推理
- 求因果联系的方法（穆勒五法）

**关键考点**：
- 完全归纳推理：对某类认识对象中每个对象具有或不具有某种属性都进行考察，从而推出该类全部对象都具有或不具有某种属性
- 不完全归纳推理：对某类认识对象中部分对象具有或不具有某种属性进行考察，从而推出该类全部对象都具有或不具有某种属性
- 提高不完全归纳推理可靠性的方法：考察更多认识对象、分析认识对象与有关现象之间的因果联系
- 探求因果联系的方法：求同法、求异法、求同求异并用法、共变法、剩余法

## 第三单元：运用辩证思维方法

### 3.1 辩证思维的含义与特征
**核心概念**：
- 辩证思维的含义
- 辩证思维的特征

**关键考点**：
- 辩证思维是用联系、发展、全面的观点看待事物和思考问题的思维
- 辩证思维的特征：
  1. **整体性**：用全面的观点看问题，从整体角度去思考
  2. **动态性**：用变化发展的观点看问题，用矛盾运动的观点看问题
- 辩证思维与诡辩论的根本区别：辩证思维用实践的观点看问题，凡未经实践检验的东西，决不能轻信和盲从

### 3.2 分析与综合及其辩证关系
**核心概念**：
- 分析
- 综合
- 分析与综合的辩证关系

**关键考点**：
- 分析：把认识对象分解为各个部分、各个要素、各个层次，或者把认识对象的复杂的发展过程分解为若干阶段，分别加以认识的一种思维方法
- 综合：把认识对象的各个部分、各个要素、各个层次和不同发展阶段，按照其固有的联系联结和统一起来进行考察的思维方法
- 分析与综合是方向相反却相辅相成的对立统一的关系
- 分析是综合的基础，综合是分析的先导

### 3.3 质量互变规律
**核心概念**：
- 质、量、度
- 量变与质变
- 质量互变规律的方法论要求

**关键考点**：
- 质：一事物成为自身并区别于他事物的内部固有的规定性
- 量：事物存在和发展的规模、程度、速度等可以用数量表示的规定性，以及事物构成因素在空间上的排列组合方式
- 度：事物保持自身质的稳定性的量的限度（范围、幅度、限度）
- 量变与质变的辩证关系：
  1. 量变是质变的必要前提
  2. 质变是量变的必然结果
  3. 质变又引起新的量变，开始一个新的发展过程
- 方法论：以统一性的观念正确把握事物发展过程中的量变与质变、渐进性与飞跃性、连续性与间断性的关系

### 3.4 推动认识发展
**核心概念**：
- 肯定方面与否定方面
- 辩证否定观
- 认识发展的历程

**关键考点**：
- 任何事物内部都包含着肯定与否定两个方面
- 肯定方面：事物保持自身存在的方面
- 否定方面：促使该事物灭亡的方面
- 辩证的否定：
  1. 具有肯定与否定的双重性
  2. 否定是对旧事物整体、旧矛盾统一体的否定
  3. 否定中所包含的肯定是对旧事物中合理因素的肯定
- 认识发展的历程：
  - 从感性具体到思维抽象
  - 从思维抽象到思维具体

## 第四单元：提高创新思维能力

### 4.1 创新思维的含义与特征
**核心概念**：
- 创新思维的含义
- 创新思维的特征

**关键考点**：
- 创新思维是特指人们在实践中破除迷信、超越陈规，有所发现、有所发明的思维活动
- 创新思维的特征：
  1. 思路具有多向性
  2. 步骤具有跨越性
  3. 结果具有独特性
- 创新思维的"新"：思路新、方法新、结果新

### 4.2 联想思维的含义与方法
**核心概念**：
- 联想思维的含义
- 联想思维的方法

**关键考点**：
- 联想思维是将记忆中对不同事物的认识进行联结与思考的思维活动
- 联想思维的客观基础：事物之间是普遍联系的
- 联想思维的特征：跨越的联结性、非逻辑制约的畅想性
- 联想思维的方法：
  1. 迁移：将不同认识对象的性质、作用等进行位置变迁与功能移植，以寻求解决问题的新思路
  2. 想象：在头脑中对已有的事物表象进行加工、改造，通过重新组合而产生新的事物形象的思维过程

### 4.3 发散思维与聚合思维的方法
**核心概念**：
- 发散思维
- 聚合思维

**关键考点**：
- **发散思维**：根据已知的事物信息，从不同的角度、不同的方向思考，以寻求解决问题的多样性答案的思维方式
- 发散思维的方法：检核表法、信息交合法、头脑风暴法
- **聚合思维**：利用已有的知识和经验，把众多信息逐步引导到条理化的逻辑思路中，以便得出合乎逻辑的解决问题的方案
- 聚合思维的方法：归纳概括、演绎推理
- 发散思维与聚合思维是创新思维的两翼，只有在两翼相互作用所形成的"合力"下，事情才能办好，科学才能进步，真理才能发展

### 4.4 逆向思维的含义与作用
**核心概念**：
- 逆向思维的含义
- 逆向思维的方法

**关键考点**：
- 逆向思维是人们从过去所把握的事物原理的反面、构成要素的反面、功能结构的反面等，去思考、去求索，以实现创新的目的
- 逆向思维的方法：
  1. 对事物结构顺序的已有认识进行反向思考
  2. 对已有的有关事物存在状态的认识作转换性思考
  3. 对已有的有关事物功能的认识作反向思考
  4. 对已有的有关事物之间因果关系的认识作交换性思考
- 逆向思维应当合"理"，不能脱离客观规律

### 4.5 超前思维的含义与特征
**核心概念**：
- 超前思维的含义
- 超前思维的特征

**关键考点**：
- 超前思维是在多角度、全方位地分析事物的历史和现状的基础上，从事物发展的现实情况出发，认识和把握事物的发展状态，运用合理的推理和想象，判断事物未来发展趋势的思维形态
- 超前思维的特征：
  1. 探索性
  2. 预测性
  3. 不确定性
- 超前思维的方法：矛盾分析方法、推理和想象的方法、调查研究方法

## 逻辑思维规则速查表

| 规则 | 内容 | 违反错误 |
|------|------|----------|
| 同一律 | A是A | 偷换概念、偷换论题 |
| 矛盾律 | A不是非A | 自相矛盾 |
| 排中律 | A或者非A | 两不可 |
| 三段论规则1 | 只能有三个不同项 | 四概念错误 |
| 三段论规则2 | 中项至少周延一次 | 中项不周延 |
| 三段论规则3 | 前提中不周延的项结论中不得周延 | 大项不当扩大/小项不当扩大 |

## 常见设问角度

1. **分析类**：分析某思维是否合乎逻辑思维要求
2. **判断类**：判断某推理类型及其有效性
3. **应用类**：运用辩证思维方法分析...
4. **创新类**：说明如何运用创新思维解决问题
5. **正误判断**：指出某逻辑错误并纠正

## 易混淆知识点

| 易混点 | 正确理解 |
|--------|----------|
| 抽象思维vs形象思维 | 前者用概念，后者用感性形象 |
| 矛盾律vs排中律 | 矛盾律要求不能同真；排中律要求不能同假 |
| 相容vs不相容选言 | 前者可同真，后者不能同真 |
| 演绎vs归纳vs类比 | 演绎是一般到个别（必然），归纳是个别到一般（或然），类比是两类比较（或然） |
| 分析vs综合 | 分析是分解，综合是整合，两者相辅相成 |
| 发散思维vs聚合思维 | 前者向外扩散求多种答案，后者向内集中求最优方案 |

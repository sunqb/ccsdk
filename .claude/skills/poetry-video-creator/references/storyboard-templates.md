# 分镜模板库

> 核心原则：**总时长封顶，分镜数封顶，旁白与画面严格同步**

## 模板索引

| 模板ID | 名称 | 分镜数上限 | 适用场景 | 总时长 |
|--------|------|-----------|---------|--------|
| `classic` | 经典赏析型 | 7 | 教学讲解，逐联分析 | 45-105s |
| `general` | 通用三段式 | 3 | 默认，新课标通用 | 45-90s |
| `immersive` | 意境沉浸型 | 5 | 艺术审美，仅绝句 | 30-45s |
| `story` | 故事叙述型 | 5 | 叙事性强的诗 | 60-90s |
| `explore` | 问答探索型 | 5 | 互动教学，探究式 | 45-60s |
| `short` | 短视频速览型 | 3 | 社交媒体 | 15-20s |

---

## classic（经典赏析型）— 默认

**总时长**：45-75秒（绝句）/ 75-105秒（律诗）

```
S1: 封面 (3s) | 远景 | 诗题+作者
  → S2: 定调 (10-15s) | 中景 | 背景/情绪（旁白：定调段）
  → S3: 朗诵全诗 (15-20s) | 全景→中景 | 诗句逐句出，画面随动
  → S4-S5: 逐联赏析 (15-20s/联) | 景别随诗意 | 旁白：品联段
  → S6: 收束 (8-10s) | 远景 | 旁白：点睛/升华段
```

**规则**：
- 绝句：S4-S5合并为1镜，总镜≤5
- 律诗：S4-S7每联1镜，总镜≤7
- 超过105秒必须删减，优先砍作者背景

---

## immersive（意境沉浸型）

**总时长**：30-45秒（仅绝句或律诗节选）

```
S1: 空镜 (3s, 无旁白) | 远景 | 环境音
  → S2: 诗行+视觉 (8-12s/句) | 全景~中景 | 旁白：仅念诗句，无解析
  → S3: 余韵 (5s, 无旁白) | 极远景 | 渐隐
```

**规则**：
- 仅用于绝句或律诗最精彩的一联
- 旁白≤诗句原文，禁止额外讲解
- 总时长超45秒自动切换为classic
- 必须≥1镜无旁白

---

## story（故事叙述型）

**总时长**：60-90秒

```
S1: 场景 (8-10s) | 远景 | 时间地点
  → S2: 人物 (8-10s) | 中景 | 动作引入
  → S3: 事件 (12-15s) | 近景→中景 | 冲突/转折
  → S4: 点题 (10-12s) | 全景 | 诗句出现
  → S5: 余韵 (8-10s) | 远景 | 动作收束
```

**规则**：
- 仅用于叙事性强的诗（石壕吏、木兰辞片段）
- 一镜一动作，禁止静态摆拍
- 旁白必须推动剧情，无纯描写句

---

## explore（问答探索型）

**总时长**：45-60秒

```
S1: 设问 (8-10s) | 中景 | 抛出一个具体悬念（如"这字为什么用得好？"）
  → S2: 线索 (10-12s) | 全景→近景 | 展示证据/画面片段，引导观察
  → S3: 破案 (8-10s) | 近景→特写 | 揭晓答案，点出关键意象或手法
  → S4: 解析 (12-15s) | 中景 | 答案背后的情感逻辑
  → S5: 收束 (5-8s) | 远景 | 一句点题
```

**规则**：
- 问题必须具体（"为什么用孤帆而不是群帆？"），禁止泛泛（"这首诗美不美？"）
- "设问→线索→破案"三段形成完整证据链，禁止只问不引证
- 每问必有答，禁止开放式结尾
- 兼容**侦探解谜型**和**因果追问型**旁白（前者侧重证据链，后者侧重因果推理）
- 总时长超60秒优先压缩 S4 解析层

---

## short（短视频速览型）

**总时长**：15-20秒

```
S1: 封面+诗眼 (3s) | 中景 | 诗题+最震撼的一句
  → S2: 核心画面 (8-12s) | 近景→全景 | 单意象极致呈现
  → S3: 点题 (3-5s) | 远景 | 诗题+作者，渐隐
```

**规则**：
- 仅一联一画面，禁止多场景切换
- 旁白≤20字，或纯音乐+字幕
- 用于社交媒体，信息极简但不缺失

---

## general（通用三段式）— 新课标默认

**总时长**：45-60秒（绝句）/ 60-90秒（律诗/古诗）

```
S1: 背景铺垫 (8-12s) | 远景→中景 | 诗人/时代画面，旁白：定位段
  → S2: 诗句画面 (20-30s) | 中景→近景→特写 | 核心意象视觉叙事，旁白：转述段
  → S3: 升华落点 (15-25s) | 近景→全景→远景 | 情感收束，旁白：升华段
```

**规则**：
- 与**通用型旁白**三段式严格对应（定位→转述→升华）
- S1 不展开诗人生平，仅一句身份定位
- S2 聚焦 1-2 个核心意象，不做逐句逐联拆分
- S3 做情感跃迁，"从具体拉到辽阔"，画面逐级拉远
- 旁白字数上限 230 字
- 总时长超 90 秒优先压缩 S2 画面篇幅
- 作为**课标模板匹配失败时的默认回退分镜**

## 特殊诗词类型

### 送别类（实景）

**总时长**：45-60秒

```
S1: 封面 (3s)
  → S2: 送者 (10-12s) | 中景 | 李白目送，旁白定调
  → S3: 行者 (8-10s) | 远景 | 孤舟远去，无旁白或仅一句
  → S4: 空江 (8-10s) | 极远景 | 帆影尽，环境音
  → S5: 独立 (10-12s) | 中景 | 李白独对，旁白点睛
  → S6: 收束 (5-8s) | 远景 | 渐隐
```

**规则**：
- S3（行者）人物≤画面5%，禁止面部
- S3-S4可合并，总镜≤5
- 旁白禁止重复"依依不舍"，用动作替代

**镜头衔接**：
- S2→S3：从送者目光方向切出 → 叠化至江面孤舟，情绪递进：怅然→空寂
- S3→S4：孤帆渐渺 → 水天浩渺无帆，情绪递进：空寂→无言
- S4→S5：从远景切至中景，空间收缩，情绪递进：无言→怅然若失

---

### 送别类（虚境/旷达）

**总时长**：30-45秒

```
S1: 封面 (3s)
  → S2: 议论 (10-12s) | 中景 | 诗人直面镜头或侧影
  → S3: 空镜 (8-10s) | 远景 | 天涯、明月、江山
  → S4: 收束 (8-10s) | 全景 | 旁白点出旷达
```

**规则**：
- 无行者视角，以空间辽阔代离别之悲
- 旁白用"海内存知己"式议论，禁止具体场景描写

---

### 叙事类诗词（石壕吏、木兰辞等）

```
S1: 场景设定 (时间/地点/氛围)
  → S2-Sn: 事件发展（按叙事弧线推进）
  → Sn+1: 诗句总结+情感升华
```

**规则**：
- 需要多个角色各自的 reference_subject
- 场景间有明确的时间/空间转换
- 旁白用story风格

## 旁白与分镜联动表

| 分镜模板 | 推荐旁白（课标模板） | 推荐旁白（年龄风格） | 旁白字数上限 | 总时长上限 | 超时处理 |
|----------|---------------------|---------------------|-------------|-----------|---------|
| general | **通用型** / 冷暖对比型 / 古今对话型 | adult / teen | 230字 | 90s | 压缩S2画面 |
| classic | 知人论世型 / 一字立骨型 / 声韵品味型 | teen / adult | 250字 | 105s | 砍作者背景 |
| immersive | 画面追踪型 / 声韵品味型 | recitation（仅诗句） | 56字（绝句） | 45s | 强制切换general |
| story | 通用型 / 知人论世型 | story | 200字 | 90s | 砍场景铺陈 |
| explore | 侦探解谜型 / 因果追问型 / 假如改写型 | child / teen | 150字 | 60s | 压缩S4解析层 |
| short | 通用型（精简版120字内） | recitation / child | 20字 | 20s | 禁止扩展 |
| 送别-实景 | 冷暖对比型 / 画面追踪型 | teen / story | 150字 | 60s | 合并行者+空江 |
| 送别-虚境 | 古今对话型 / 知人论世型 | teen / adult | 100字 | 45s | 砍议论层 |
| 叙事类 | 通用型 / 知人论世型 | story | 200字 | 90s | 砍背景铺陈 |

> **选择规则**：优先匹配课标模板 → 无法匹配时回退年龄风格 → 仍无法匹配时使用**通用型+general**作为兜底。

## 生成校验清单

生成分镜前自动检查：

```
□ 总时长是否超过模板上限？
□ 分镜数是否超过上限（general≤3, classic≤7, immersive≤5, story≤5, explore≤5, short≤3）？
□ 送别类是否区分实景/虚境？
□ immersive是否≥1镜无旁白？
□ 每镜是否有明确景别和镜头运动？
□ 旁白字数是否超过联动表上限？
□ 旁白与画面是否同步（每句对应可见元素）？
```

全部通过才输出，否则自动精简。

## 新增模板指南

新增分镜模板时，需提供以下信息：

```markdown
### [template_id]（中文名称）

分镜结构：S1 → S2 → ... → Sn（标注每段时长范围）
适用场景：何种诗词类型
总时长：典型范围
分镜数上限：最多几镜
超时处理：超过上限时砍什么
```

在 SKILL.md 的模板索引表中追加一行即可生效。

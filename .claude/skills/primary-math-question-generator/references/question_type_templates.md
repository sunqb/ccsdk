# 小学数学题型模板与设问方式

## 一、填空题

### 概念识记型

**特点**：考查基本概念、公式、性质的记忆。

**常见设问**：
- _______叫做_______。
- _______的_______是_______。
- _______和_______相乘，积是_______。

**示例**：
```
长方形的面积 = _______ × _______
```

**仿写策略**：
- 更换考查的概念
- 更换公式中的要素
- 改为反向填空（求未知数）

---

### 计算型

**特点**：直接计算，考查计算技能。

**常见设问**：
- 直接写出得数。
- _______ + _______ = _______
- _______ 的 _______ 倍是 _______

**示例**：
```
24 × 5 = _______
```

**仿写策略**：
- B类变式：只改数字
- 改变运算类型
- 改为求未知数（逆向）

---

### 规律探索型

**特点**：发现规律并应用。

**常见设问**：
- 按规律填数：1，3，5，7，_______
- 观察下列算式，你发现了什么规律？

**示例**：
```
观察：1×1=1，11×11=121，111×111=12321
      那么1111×1111=_______
```

**仿写策略**：
- 更换规律类型（数字规律、图形规律等）
- 更换数列或算式
- 增加规律的复杂程度

---

## 二、选择题

### 概念辨析型

**特点**：考查对易混概念的辨析。

**常见设问**：
- 下面说法正确的是（    ）
- _______和_______的区别是（    ）

**示例**：
```
下面说法正确的是（    ）
A. 长方形是特殊的正方形
B. 正方形是特殊的长方形
C. 平行四边形是特殊的长方形
D. 梯形是特殊的平行四边形
```

**仿写策略**：
- 更换考查的概念
- 更换选项中的易混点
- 设计不同的错误类型

---

### 计算选择型

**特点**：通过计算选择正确答案。

**常见设问**：
- _______的结果是（    ）
- 与_______相等的算式是（    ）

**示例**：
```
125 × 32 的简便算法是（    ）
A. 125 × 4 × 8
B. 125 × 8 × 4
C. 125 × 30 + 2
D. 125 × 30 × 2
```

**仿写策略**：
- 更换算式
- 更换考查的计算方法
- 设计不同的简便算法选项

---

### 情境应用型

**特点**：在具体情境中选择。

**常见设问**：
- 解决这个问题，应该（    ）
- 下列方案中，最优的是（    ）

**示例**：
```
用一根长24厘米的铁丝围成一个长方形（长宽都是整厘米数），
面积最大的是（    ）
A. 长11厘米，宽1厘米
B. 长10厘米，宽2厘米
C. 长8厘米，宽4厘米
D. 长7厘米，宽5厘米
```

**仿写策略**：
- 更换情境
- 更换需要选择的对象
- 设计不同的干扰项

---

## 三、判断题

### 概念判断型

**特点**：判断数学概念、性质的表述是否正确。

**常见设问**：
- _______。（判断对错）
- 对的打"√"，错的打"×"。

**示例**：
```
两条平行线之间的距离处处相等。（    ）
```

**仿写策略**：
- 更换考查的概念
- 设计典型的错误表述
- 更换判断的角度

---

### 计算判断型

**特点**：判断计算或解题过程是否正确。

**常见设问**：
- 下面的计算对吗？
- 小明这样做对吗？

**示例**：
```
125 × 32 = 125 × (4 × 8) = 125 × 4 + 125 × 8 = 500 + 1000 = 1500
上面的计算对吗？（    ）
```

**仿写策略**：
- 更换算式
- 设计不同的错误类型
- 更换判断的对象

---

## 四、计算题

### 直接写出得数（口算）

**特点**：考查基本口算能力。

**常见设问**：
- 直接写出得数。
- 口算。

**示例**：
```
25 × 4 =      125 × 8 =      3.6 + 6.4 =
```

**仿写策略**：
- B类变式：只改数字
- 更换运算类型
- 调整难度（整十整百数）

---

### 竖式计算

**特点**：考查笔算方法和书写规范。

**常见设问**：
- 用竖式计算。
- 列竖式计算，带*的要验算。

**示例**：
```
308 × 25 =      * 425 ÷ 25 =
```

**仿写策略**：
- 更换算式
- 更换需要验算的题目
- 调整数字难度

---

### 脱式计算（简便运算）

**特点**：考查运算顺序和简便方法。

**常见设问**：
- 计算下面各题，能简算的要简算。
- 用简便方法计算。

**示例**：
```
125 × 32 × 25
= 125 × (8 × 4) × 25
= (125 × 8) × (4 × 25)
= 1000 × 100
= 100000
```

**仿写策略**：
- 更换算式
- 更换简便方法（如乘法分配律、结合律等）
- 设计可以多种方法简便计算的题目

---

### 解方程

**特点**：考查解方程的方法和等式性质。

**常见设问**：
- 解方程。
- 求未知数x。

**示例**：
```
3x + 5 = 20
解：3x = 20 - 5
    3x = 15
     x = 5
```

**仿写策略**：
- 更换方程类型
- 调整方程难度
- 设计有实际背景的方程

---

## 五、解决问题（应用题）

### 一步应用题

**特点**：只需一步计算即可解决。

**常见设问**：
- _______是多少？
- 一共_______多少？

**示例**：
```
小明买了3支铅笔，每支2元，一共花了多少钱？
```

**仿写策略**：
- 更换情境
- 更换数量关系
- B类变式：只改数据

---

### 两步应用题

**特点**：需要两步计算才能解决。

**常见设问**：
- 先求_______，再求_______。
- _______后，_______是多少？

**示例**：
```
学校买来120本故事书，每班分20本，可以分给几个班？
如果每班分30本呢？
```

**仿写策略**：
- 更换情境
- 更换数量关系组合
- 改为多步或单步变式

---

### 多步综合应用题

**特点**：需要三步或以上计算，涉及多个知识点。

**常见设问**：
- 根据以上信息，你能解决什么问题？
- 请解决以下问题：

**示例**：
```
一个长方体水池，长8米，宽5米，深2米。
（1）这个水池占地多少平方米？
（2）水池四壁和底面贴上瓷砖，贴瓷砖的面积是多少？
（3）这个水池最多能装多少立方米水？
```

**仿写策略**：
- 更换情境
- 更换考查的知识点组合
- 增加或减少问题个数

---

### 比较类应用题

**特点**：涉及两个量的比较。

**常见设问**：
- _______比_______多多少？
- _______是_______的几倍？

**示例**：
```
小明有24本书，小红有18本书。小明比小红多几本？
```

**仿写策略**：
- 更换比较方式（多多少、少多少、几倍等）
- 更换情境
- 改为"知道差，求原数"的逆向变式

---

### 归一/归总问题

**特点**：先求单一量或总量，再求其他。

**常见设问**：
- 照这样计算，_______？
- 如果_______，可以_______？

**示例**：
```
3台拖拉机4小时耕地48公顷。照这样计算，5台拖拉机6小时耕地多少公顷？
```

**仿写策略**：
- 更换情境
- 更换归一或归总的类型
- 调整步骤复杂度

---

### 和差倍问题

**特点**：已知和、差、倍中的两个条件，求两个数。

**常见设问**：
- 两个数的和是_______，差是_______，这两个数分别是多少？
- 大数是小数的_______倍，两数之和是_______，求这两个数。

**示例**：
```
甲乙两数的和是48，甲数是乙数的3倍，甲乙两数各是多少？
```

**仿写策略**：
- 更换条件组合（和差、和倍、差倍）
- 更换数字
- 改为方程解法或算术解法

---

### 工程问题

**特点**：涉及工作效率、工作时间、工作量。

**常见设问**：
- 合作完成需要多少天？
- 还剩多少没有完成？

**示例**：
```
一项工程，甲队单独做10天完成，乙队单独做15天完成。
两队合作，几天可以完成？
```

**仿写策略**：
- 更换情境
- 更换条件（给出部分完成情况）
- 改为三人合作或轮流做

---

### 行程问题

**特点**：涉及速度、时间、路程。

**常见设问**：
- 相遇需要多长时间？
- 相距多少千米？

**示例**：
```
甲乙两车从A、B两地同时相向开出，甲车每小时行60千米，乙车每小时行40千米，
3小时后相遇。A、B两地相距多少千米？
```

**仿写策略**：
- 更换行程类型（相向、相背、同向追及）
- 更换情境（步行、骑车、开车等）
- 改为求速度或时间

---

### 分数百分数应用题

**特点**：涉及分数、百分数的实际应用。

**常见设问**：
- _______的几分之几是多少？
- 比_______多（少）百分之几？

**示例**：
```
一本书120页，第一天看了全书的1/4，第二天看了全书的1/3，还剩多少页？
```

**仿写策略**：
- 更换情境
- 更换分数百分数
- 改为已知部分求整体（逆向）

---

## 六、操作题

### 测量类

**特点**：实际测量操作。

**常见设问**：
- 量一量，_______。
- 画出长_______厘米的线段。

**示例**：
```
量出下面长方形的长和宽，并计算周长和面积。
```

---

### 画图类

**特点**：根据要求画图。

**常见设问**：
- 画出_______。
- 在方格纸上画出_______。

**示例**：
```
在方格纸上画一个面积为12平方厘米的长方形（每个小方格边长为1厘米）。
```

---

### 图形变换类

**特点**：平移、旋转、轴对称等操作。

**常见设问**：
- 将图形向_______平移_______格。
- 画出图形绕点_______旋转_______度后的图形。

**示例**：
```
画出三角形ABC绕点B顺时针旋转90度后的图形。
```

---

## 七、探究题

### 规律探索

**特点**：发现数学规律。

**常见设问**：
- 你发现了什么规律？
- 根据规律，_______。

**示例**：
```
观察下列算式：
1 + 3 = 4 = 2²
1 + 3 + 5 = 9 = 3²
1 + 3 + 5 + 7 = 16 = 4²

（1）你发现了什么规律？
（2）根据规律，1 + 3 + 5 + ... + 19 = ?
```

---

### 方案设计

**特点**：设计满足条件的方案。

**常见设问**：
- 可以怎样_______？
- 请设计_______。

**示例**：
```
有24人要坐船过河，大船每条坐6人，小船每条坐4人。
可以怎样租船？（每条船都坐满）
```

---

### 开放探究

**特点**：条件或结论开放。

**常见设问**：
- 你能提出什么数学问题？
- 还能怎样_______？

**示例**：
```
用1、2、3、4四个数字组成两个两位数，使它们的乘积最大。
这两个数分别是多少？
```

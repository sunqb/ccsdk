# 小学数学各学段语言规范标准

## 一、总体要求

### 1.1 语言表述原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **准确性** | 数学概念表述准确，无歧义 | 用"除以"而非"除" |
| **简洁性** | 简明扼要，不冗长 | 避免重复叙述 |
| **适切性** | 符合学生认知水平和阅读经验 | 低年级多用图示 |
| **规范性** | 符合数学表达规范 | 数字、单位、符号使用规范 |

### 1.2 禁止使用的表述

| 不规范表述 | 规范表述 | 说明 |
|------------|----------|------|
| 5除15 | 15除以5 或 5除15的商 | 区分"除以"和"除" |
| 增加到3倍 | 增加到3倍/增加了2倍 | 区分两种表述 |
| 扩大3倍 | 扩大到原来的3倍 | 避免歧义 |
| 除以5余3 | 除以5余3，商是... | 完整表述 |
| 约等于3 | ≈3 或 约等于3 | 符号或文字统一 |

## 二、各学段语言特点

### 2.1 第一学段（1-2年级）

#### 语言特点
- **简短**：句子简短，一般不超过15个字
- **具体**：使用具体形象的语言
- **重复**：重要信息可重复强调
- **图示**：多用图画、图示辅助理解

#### 规范表述示例

| 类型 | 规范表述 |
|------|----------|
| 计算题 | 直接写出得数。 |
| 填空题 | 在括号里填上合适的数。 |
| 比大小 | 在○里填上"＞""＜"或"＝"。 |
| 应用题 | 根据图意列式计算。 |
| 操作题 | 画一画，量一量。 |

#### 数字使用
- 1-20用阿拉伯数字或汉字均可
- 计算题用阿拉伯数字
- 文字叙述中数字可用汉字

#### 常见句式
```
一共有多少？
还剩多少？
谁比谁多（少）几？
几个几是多少？
平均分给几人，每人几个？
```

### 2.2 第二学段（3-4年级）

#### 语言特点
- **完整**：句子完整，逻辑清晰
- **准确**：数学术语使用准确
- **过渡**：逐步从具体向抽象过渡
- **图示**：适当使用线段图、示意图

#### 规范表述示例

| 类型 | 规范表述 |
|------|----------|
| 计算题 | 列竖式计算，带*的要验算。 |
| 简便运算 | 用简便方法计算。 |
| 填空题 | 在横线上填上适当的数或单位。 |
| 应用题 | 先写出数量关系式，再列式解答。 |
| 操作题 | 按要求画一画。 |

#### 数字使用
- 全部使用阿拉伯数字
- 单位用字母或汉字规范表示

#### 常见句式
```
求______是多少？
先求______，再求______。
根据______，可以知道______。
______是______的几倍？
照这样计算，______。
```

### 2.3 第三学段（5-6年级）

#### 语言特点
- **严谨**：表述严谨，逻辑严密
- **抽象**：可使用较抽象的语言
- **综合**：可涉及多个知识点的综合表述
- **规范**：数学符号、公式使用规范

#### 规范表述示例

| 类型 | 规范表述 |
|------|----------|
| 计算题 | 计算下面各题，能简算的要简算。 |
| 解方程 | 解方程。 |
| 填空题 | 在括号里填上合适的数或单位名称。 |
| 应用题 | 列式解答，并写出答语。 |
| 探究题 | 观察下面的算式，你发现什么规律？ |

#### 数学符号使用

| 符号 | 使用场景 | 示例 |
|------|----------|------|
| + - × ÷ | 四则运算 | 25 + 36 = 61 |
| = | 等于 | 5 × 6 = 30 |
| ≈ | 约等于 | 3.14 ≈ 3 |
| > < | 大于、小于 | 5 > 3 |
| : | 比 | 3:4 |
| % | 百分号 | 25% |
| π | 圆周率 | C = πd |
| a² | 平方 | 面积 = a² |

#### 常见句式
```
设______为x，根据题意列方程。
根据______的数量关系，列式计算。
通过计算发现______。
你还能提出什么数学问题？
验证你的结论是否正确。
```

## 三、数学概念表述规范

### 3.1 数的认识

| 概念 | 规范表述 | 不规范表述 |
|------|----------|------------|
| 数位 | 从右起第一位是个位 | 右边第一位叫个位 |
| 计数单位 | 个、十、百、千... | 个位、十位、百位...（混淆数位和计数单位） |
| 因数倍数 | 3是12的因数，12是3的倍数 | 3是12的约数（旧称） |
| 质数 | 只有1和它本身两个因数的数 | 只能被1和本身整除的数（不严谨） |
| 倒数 | 乘积是1的两个数互为倒数 | 倒过来的数 |

### 3.2 数的运算

| 概念 | 规范表述 | 不规范表述 |
|------|----------|------------|
| 加法交换律 | 两个加数交换位置，和不变 | 交换加数位置和不变 |
| 乘法分配律 | 两个数的和与一个数相乘... | 括号外面的数分别乘括号里面的数 |
| 商不变性质 | 被除数和除数同时乘或除以相同的数（0除外），商不变 | 被除数和除数同时扩大或缩小相同倍数... |
| 有余数除法 | 被除数 = 商 × 除数 + 余数 | 被除数等于商乘除数加余数（无数学味） |

### 3.3 图形与几何

| 概念 | 规范表述 | 不规范表述 |
|------|----------|------------|
| 周长 | 封闭图形一周的长度 | 边的总长度（不严谨） |
| 面积 | 物体表面或平面图形的大小 | 有多大（口语化） |
| 体积 | 物体所占空间的大小 | 容积（混淆概念） |
| 平行线 | 在同一平面内不相交的两条直线 | 不相交的两条直线（缺少前提） |
| 垂直 | 两条直线相交成直角，就说这两条直线互相垂直 | 两条线成90度 |

### 3.4 统计与概率

| 概念 | 规范表述 | 不规范表述 |
|------|----------|------------|
| 平均数 | 一组数据的总和除以数据的个数 | 加起来除以个数（口语化） |
| 中位数 | 一组数据按大小排列，处于中间位置的数 | 中间那个数（不严谨） |
| 众数 | 一组数据中出现次数最多的数 | 出现最多的数（口语化） |
| 可能性 | 用"一定""可能""不可能"描述 | 也许、大概（不规范） |

## 四、单位使用规范

### 4.1 长度单位

| 单位 | 符号 | 使用示例 |
|------|------|----------|
| 千米 | km | 路程：甲乙两地相距150 km |
| 米 | m | 身高：1.45 m |
| 分米 | dm | 较少使用 |
| 厘米 | cm | 长度：铅笔长15 cm |
| 毫米 | mm | 厚度：硬币厚2 mm |

### 4.2 面积单位

| 单位 | 符号 | 使用示例 |
|------|------|----------|
| 平方千米 | km² | 国土面积 |
| 公顷 | hm² | 土地面积 |
| 平方米 | m² | 房间面积 |
| 平方分米 | dm² | 课桌面面积 |
| 平方厘米 | cm² | 指甲面积 |

### 4.3 体积（容积）单位

| 单位 | 符号 | 使用示例 |
|------|------|----------|
| 立方米 | m³ | 仓库容积 |
| 立方分米 | dm³ | 体积计算 |
| 立方厘米 | cm³ | 小物体体积 |
| 升 | L | 液体容量 |
| 毫升 | mL | 液体容量 |

### 4.4 质量单位

| 单位 | 符号 | 使用示例 |
|------|------|----------|
| 吨 | t | 货车载重 |
| 千克 | kg | 人的体重 |
| 克 | g | 小物品质量 |

### 4.5 时间单位

| 单位 | 使用示例 |
|------|----------|
| 时 | 1时30分 |
| 分 | 45分 |
| 秒 | 30秒 |
| 年、月、日 | 2024年3月15日 |

## 五、应用题表述规范

### 5.1 已知条件表述

```
规范：小明有24本书，小红有18本书。
规范：一个长方形长8 cm，宽5 cm。
规范：汽车每小时行驶60 km，行驶了3小时。
```

### 5.2 问题表述

```
规范：一共有多少本？
规范：面积是多少平方厘米？
规范：甲乙两地相距多少千米？
规范：平均每小时行多少千米？
```

### 5.3 答语规范

```
规范：答：一共有42本书。
规范：答：面积是40平方厘米。
规范：答：甲乙两地相距180千米。
```

